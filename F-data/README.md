# Bundled benchmark and scoring artifacts

| File | Contents |
| --- | --- |
| `processbench_cached.parquet` | Frozen 3,400-row ProcessBench snapshot with project convenience columns. |
| `processbench_full_results.parquet` | Saved ReasonEval scores for all 3,400 solutions, including step scores and per-row timings. |
| `processbench_08_results.csv` | Earlier 570-row sample scoring results. |

These three files are byte-for-byte copies from the course-project review archive. They provide inputs for the published CPU notebooks. The stratified sample can be regenerated by Notebook 1 and is saved under `generated-results/`.

## Attribution and terms

ProcessBench was introduced by Chujie Zheng et al., *ProcessBench: Identifying Process Errors in Mathematical Reasoning*, ACL 2025. [Paper](https://arxiv.org/abs/2412.06559) · [Official repository](https://github.com/QwenLM/ProcessBench) · [Dataset](https://huggingface.co/datasets/Qwen/ProcessBench).

The upstream dataset card lists **Apache-2.0**. A copy of the [license](../licenses/Apache-2.0.txt) and the [upstream card](UPSTREAM_DATASET_CARD.md) are included. The project cache is a transformed Parquet snapshot with derived columns; the score files contain project-produced evaluator outputs and benchmark metadata. Existing data bytes were preserved for analysis reproducibility. The upstream card reflects the current source and does not establish the exact original dataset revision.

No model weights or model caches are included. Model and upstream code licenses remain separate from the dataset license. ReasonEval's repository and model card differ in their 7B licensing descriptions; consult both upstream sources before redistributing weights.
